# Task 2 — Calculator

A responsive calculator built with HTML, CSS, and JavaScript for the DecodeLabs internship.

## Requirements covered

- Basic calculator UI
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Buttons and display screen
- User input handling
- Clear button (AC)
- Delete button (DEL)
- Real-time result preview
- Keyboard support
- Responsive design
- Styling enhancement
- Light/dark theme toggle

## How to run

Open `index.html` directly in a browser.

No framework or installation is required.

## Keyboard controls

- `0–9` → numbers
- `+ - * /` → arithmetic operations
- `.` → decimal
- `Enter` or `=` → calculate
- `Backspace` → delete
- `Esc` → clear
